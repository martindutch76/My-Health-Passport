Nothing is uploaded. This file never leaves your device — it's read, processed, and re-saved entirely in your browser. This page has no server, and loads no external code beyond fonts.

Technical note — file requirements

The uploaded file must contain at least 5 columns, and must include a unique record ID, a First Name, Last Name, Date of Birth, and Gender column.

Accepted gender coding

SLK-581 defines exactly four sex/gender codes. Matching against your Gender column is case-insensitive and ignores leading/trailing whitespace — "Female", "FEMALE", and " female " are all read identically.
