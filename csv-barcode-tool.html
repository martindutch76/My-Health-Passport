Bulk SHA-256 conversion

Linking Key Table Generator

Convert an existing set of SLK-581 statistical linkage keys into My Health Passport Barcodes — one-way SHA-256 hashes — producing a linkage table that pairs each original key with its Barcode, so the two can be linked against your current SLK-581-enabled datasets.

Nothing is uploaded. All data is transformed locally in your browser. This page has no server, and loads no external code beyond fonts.

Technical note — file requirements

This tool expects a single-column CSV containing one SLK-581 per row. It is designed for small, spreadsheet-sized projects — everything is held in your browser's working memory rather than processed in chunks on a server.

Recommended for batches of less than 250,000 rows. Larger files may slow down or strain the browser, especially on older or memory-constrained devices; for anything approaching that scale, consider the SQL-based coding approach instead.

Before you upload

  • The file must contain exactly one column of data throughout.
  • Each SLK-581 value should contain only letters and numbers — no symbols or punctuation.
  • Each value should contain a mix of letters and numbers, consistent with a real SLK-581.

A file that doesn't meet these rules will still open — you'll see a one-time notice summarising what looks off, so you can decide whether to continue.
